# \# 🩺 Breast Cancer Detection System

# 

# An AI-powered breast cancer detection web application built with \*\*VGG16 Transfer Learning\*\*, \*\*Streamlit\*\*, and \*\*MySQL\*\*.

# 

# \## 🔗 Live Demo

# 👉 \[breast-cancer-detection-project-production.up.railway.app](https://breast-cancer-detection-project-production.up.railway.app)

# 

# \## 📌 About

# This system classifies breast ultrasound images as \*\*Benign\*\* or \*\*Malignant\*\* using a fine-tuned VGG16 deep learning model trained on the BUSI dataset.

# 

# \## ✨ Features

# \- 🔬 AI-powered image classification (Benign / Malignant)

# \- 👥 Role-based login (Admin, Doctor, Radiologist, Researcher)

# \- 📋 Prediction history with filtering

# \- 📊 Dashboard with charts and statistics

# \- ✏️ Update and verify predictions

# \- 🗑️ Delete records

# \- 👥 User management

# 

# \## 🛠️ Tech Stack

# \- \*\*Frontend:\*\* Streamlit

# \- \*\*Model:\*\* VGG16 Transfer Learning (Keras)

# \- \*\*Dataset:\*\* BUSI (780 ultrasound images)

# \- \*\*Database:\*\* MySQL

# \- \*\*Deployment:\*\* Railway

# \- \*\*Model Hosting:\*\* Hugging Face Hub
